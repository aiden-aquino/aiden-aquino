## Research

**Mathematical Threat Modeling for IT/OT Convergence in Hyperscale Data Centers** *(CCI Grant, with Red Trident, Inc.)*
Threat modeling the attack surface created when once-isolated OT and physical security systems converge onto shared IP networks. I lead the Bayesian attack graph and probabilistic inference work, and authored the project's prior-provenance methodology — a set of cited rules under which a probability with no traceable source does not enter the model.

**AI-Powered Digital Twin for Water Distribution System Cybersecurity** *(CCI Grant)*
A digital twin of a water treatment plant built from real ICS attack telemetry (iTrust SWaT, BATADAL), behind an operator dashboard that recommends mitigations but never executes them. I built the ingestion pipeline, S3 dataset sync, and FastAPI dashboard, and two unsupervised anomaly detectors — a scikit-learn Isolation Forest and a PyTorch LSTM autoencoder.
